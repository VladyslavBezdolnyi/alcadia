# Privacy Policy — Pinterest Board Backup

Last updated: 21 July 2026

Pinterest Board Backup is a personal, single-user tool that downloads images
from the operator's own Pinterest boards to the operator's own computer.

## Scope

This tool is operated by one individual for their own Pinterest account. It has
no other users. It offers no accounts, no sign-up, and no hosted service.

## What it accesses

Through the Pinterest API, using only the `boards:read` and `pins:read` scopes:

- the list of boards on the operator's own Pinterest account
- the pins on those boards, including their image URLs

## What it stores

- Image files from the operator's own boards, saved to local disk.
- The Pinterest access token, held in a local environment variable on the same
  machine.

Nothing is transmitted to any server run by the developer or to any third
party. There is no backend, no database, no analytics, no telemetry, and no
advertising.

## Sharing

None. No Pinterest data is sold, published, or disclosed to anyone.

## Retention and deletion

All data is local. It can be deleted at any time by removing the downloaded
files. API access can be revoked at any time from Pinterest account settings.
